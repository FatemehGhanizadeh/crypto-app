# 📈 داشبورد ارزهای دیجیتال

یک داشبورد تحت وب برای مشاهده و بررسی اطلاعات بازار ارزهای دیجیتال که با استفاده از **React** و API وب‌سایت CoinGecko توسعه داده شده است. این پروژه امکان جست‌وجوی ارزهای دیجیتال، مشاهده اطلاعات بازار و بررسی نمودار تغییرات آن‌ها را فراهم می‌کند.

## ✨ ویژگی‌ها

- نمایش اطلاعات ارزهای دیجیتال شامل نام، نماد، قیمت فعلی، حجم معاملات و تغییرات بازار
- پشتیبانی از انتخاب واحد پولی دلار آمریکا (USD)، یورو (EUR) و ین ژاپن (JPY)
- جست‌وجوی ارزهای دیجیتال
- صفحه‌بندی برای مشاهده فهرست ارزها
- نمایش نمودار اطلاعات تاریخی هر ارز در بازه‌ی ۷ روز گذشته
- امکان تغییر نوع نمودار بین قیمت (Prices)، ارزش بازار (Market Caps) و حجم معاملات (Total Volumes)
- نمایش اطلاعات تکمیلی مانند قیمت فعلی، بالاترین قیمت تاریخی (ATH) و ارزش بازار (Market Cap)
- نمایش وضعیت بارگذاری هنگام دریافت اطلاعات
- طراحی کامپوننت‌های قابل استفاده مجدد در React

## 🛠️ تکنولوژی‌های استفاده‌شده

- **React** — ساخت رابط کاربری
- **JavaScript (ES6+)** — پیاده‌سازی منطق برنامه
- **CSS Modules** — استایل‌دهی کامپوننت‌ها
- **Recharts** — رسم نمودارهای تعاملی
- **CoinGecko API** — دریافت اطلاعات ارزهای دیجیتال
- **Fetch API** — ارسال درخواست‌های HTTP
- **React Hooks** — مدیریت state و چرخه‌ی حیات کامپوننت‌ها
- **React Loader Spinner** — نمایش وضعیت بارگذاری

## 📊 نمودارهای تعاملی

با انتخاب هر ارز دیجیتال، نمودار اطلاعات تاریخی آن نمایش داده می‌شود. کاربر می‌تواند بین سه نوع داده جابه‌جا شود:

- **Prices:** تغییرات قیمت
- **Market Caps:** تغییرات ارزش بازار
- **Total Volumes:** تغییرات حجم معاملات

همچنین اطلاعاتی مانند قیمت فعلی، بالاترین قیمت تاریخی و ارزش بازار ارز انتخاب‌شده نمایش داده می‌شوند.

## 🌐 منبع داده

اطلاعات بازار و داده‌های تاریخی از طریق [CoinGecko API](https://www.coingecko.com/en/api) دریافت می‌شوند.

## 🚀 بهبودهای آینده

- بهبود تجربه کاربری در دستگاه‌های موبایل
- مدیریت بهتر خطاهای API و وضعیت‌های بارگذاری
- بهبود قالب‌بندی اعداد و قیمت‌ها
- افزودن امکان انتخاب ارز از نتایج جست‌وجو
- افزودن تست برای کامپوننت‌ها و توابع برنامه
